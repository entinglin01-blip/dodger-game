# 躲避遊戲 🎮

一個簡單又好玩的網頁動作遊戲！

## 遊戲玩法 🎯

- **移動**: ⬅️ ➡️ 方向鍵或 A/D 鍵
- **跳躍**: ⬆️ 方向鍵或空白鍵
- **躲避**: 避開紅色的障礙物
- **收集**: 拾取金色星星增加分數
- **生命**: 生命用完遊戲結束

## 遊戲特色 ✨

✅ 簡單易上手的操控方式  
✅ 漸進式難度提升  
✅ 分數計算系統  
✅ 最高分記錄（本地儲存）  
✅ 美觀的視覺設計  
✅ 響應式設計，支援不同螢幕尺寸  

## 遊戲機制 🎲

1. **躲避障礙物**: 每個成功躲避的障礙物 +5 分
2. **收集星星**: 每個星星 +10 分
3. **難度提升**: 遊戲進行時，難度會逐漸提升
4. **生命系統**: 初始 3 條生命，碰到障礙物失去 1 條

## 技術棧 💻

- HTML5
- CSS3
- JavaScript (Canvas API)
